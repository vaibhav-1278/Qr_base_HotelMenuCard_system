## QR-Based Digital Menu & Restaurant Management System

This project is a **QR-based digital menu and restaurant management system** designed to simplify the food ordering process for both customers and restaurant staff.

Customers can simply **scan the QR code placed on their table** using their smartphone to access the digital menu. They can browse available food items, view prices and details, select items, and place orders directly from their table without requiring a physical menu or manual order-taking process.

Once an order is placed, it is automatically displayed on the **Kitchen Dashboard**, where kitchen staff can view and manage orders **table-wise**. This helps the kitchen team easily identify which items belong to which table and improves order management.

The system also provides an **Admin Dashboard** for managing menu items, categories, tables, orders, and other restaurant operations. The admin can monitor orders and the system can **automatically generate bills for individual tables** based on the ordered items and quantities.

### Key Features

* QR code-based digital menu
* Customers can scan QR codes from their tables
* Digital food menu with item details and prices
* Online table-wise food ordering
* Kitchen dashboard for managing orders
* Table-wise order tracking
* Admin dashboard
* Menu and food item management
* Order management
* Automatic bill generation
* Table-wise billing
* Responsive and user-friendly interface

### Technologies Used

* **PHP**
* **CodeIgniter**
* **MySQL**
* **Bootstrap**
* **QR Code Generator**

### Project Objective

The main objective of this project is to **digitize and simplify restaurant operations** by replacing traditional paper menus and manual order-taking with a QR-based digital ordering system. It helps improve the customer ordering experience, reduce manual work, organize kitchen orders efficiently, and simplify restaurant billing and management.
